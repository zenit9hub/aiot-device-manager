#### Slide - 주요 AWS 서비스 소개

개발 및 배포 관련 주요 AWS 서비스 
- Amplify
	- 프론트엔드 배포 및 풀스택 애플리케이션 개발 지원

	- CI/CD 파이프라인 자동화 및 오케스트레이션
	- 코드 변경 사항을 자동으로 빌드, 테스트, 배포
	- GitHub, AWS CodeCommit 등 다양한 소스 저장소 연동

- CodeBuild
	- 클라우드 기반 소스 코드 빌드 자동화
	- 확장 가능한 컨테이너 기반 빌드 실행 환경 제공
	- CI/CD 파이프라인과 연계하여 빌드 최적화

- CodeDeploy
	- EC2, Lambda, 온프레미스 환경에 애플리케이션 자동 배포
	- 블루/그린 배포, 롤링 업데이트 지원
	- 자동 롤백(Auto Rollback) 기능 제공, 배포 실패 시 복구 가능

``` 스크립트
1️⃣ AWS Amplify – 프론트엔드 배포 및 풀스택 애플리케이션 개발 지원
AWS Amplify는 프론트엔드 애플리케이션 배포에 최적화된 서비스로, 정적 웹사이트 및 서버리스 애플리케이션을 쉽게 구축하고 배포할 수 있도록 지원합니다. GitHub, GitLab, Bitbucket과 연동하여 자동화된 CI/CD(Continuous Integration & Deployment) 파이프라인을 제공하며, 인증, API, 데이터 저장소 등 백엔드 기능도 함께 구성할 수 있습니다.
2️⃣ AWS CodePipeline – CI/CD 파이프라인 오케스트레이션
AWS CodePipeline은 애플리케이션 배포 프로세스를 자동화하는 CI/CD(Continuous Integration & Continuous Deployment) 서비스입니다. GitHub, CodeCommit 등의 소스 코드 저장소와 통합하여 코드 변경 사항을 자동으로 빌드, 테스트 및 배포할 수 있으며, DevOps 워크플로우를 효율적으로 관리할 수 있도록 지원합니다.
3️⃣ AWS CodeBuild – 클라우드 기반 소스 코드 빌드 자동화
AWS CodeBuild는 소스 코드를 자동으로 컴파일하고, 테스트 및 패키징하는 완전 관리형 빌드 서비스입니다. 빌드 서버를 직접 운영할 필요 없이 클라우드 환경에서 확장 가능한 컨테이너 기반 빌드 실행 환경을 제공하며, CodePipeline과 연계하여 CI/CD 파이프라인을 강화할 수 있습니다.
4️⃣ AWS CodeDeploy – 애플리케이션 배포 자동화 및 롤백 기능 제공
AWS CodeDeploy는 EC2, Lambda, 온프레미스 서버 등 다양한 환경에 애플리케이션을 자동 배포하는 서비스입니다. 블루/그린 배포(Blue/Green Deployment), 롤링 업데이트(Rolling Update) 등의 배포 전략을 지원하며, 배포 실패 시 자동 롤백(Auto Rollback) 기능을 통해 안정적인 서비스 운영을 보장합니다.
```
