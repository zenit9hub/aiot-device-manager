# 플랫폼 강의 구성 목적

## 1. 목적
본 강의는 협회 강의 5회차를 맞아, 기존 커리큘럼의 큰 틀은 유지하되 지난 회차 피드백을 반영하여 핵심 메시지와 학습 흐름을 더 명확하게 보강한 과정입니다.  
협회 커리큘럼만 보고 참여한 수강생도 혼선 없이 내용을 이해하고, 더 높은 만족도를 얻을 수 있도록 하는 것이 목적입니다.

## 2. 강의 범위와 교육적 의도
본 강의는 2일 동안 `기획`, `설계`, `구축`, `배포`를 하나의 흐름으로 이해하도록 돕는 과정입니다.  
각 직무 영역의 세부 기술을 모두 깊게 다루기보다는, 프로젝트 생애주기를 전체적으로 조망하고 각 단계가 어떻게 연결되는지를 이해하는 데 초점을 둡니다.

이를 통해 수강생은 자신의 R&R을 넘어 인접 직무를 이해하고, 협업에 필요한 공통 언어와 PMO 관점의 시야를 넓힐 수 있습니다.  
또한 본 강의는 스타트업이나 2~3인 개발 체제처럼 적은 인원으로 MVP 프로젝트를 빠르게 기획하고 개발해야 하는 환경에도 실질적으로 도움이 되도록 설계되었습니다.

다만 2일 안에 기획부터 설계, 구축, 배포까지 모두 다루는 만큼, 각 챕터의 세부 기술은 전부 심화하기 어렵습니다.  
따라서 본 강의는 전체 흐름을 이해하는 데 중점을 두고, 세부 기술은 이후 심화 학습으로 확장해 나가도록 안내합니다.

## 3. 운영 원칙
강의는 사전에 준비된 MVP 샘플 프로젝트와 그에 대응하는 기획·설계 문서를 기반으로 진행합니다.  
수강생은 이를 바탕으로 전체 흐름을 따라가되, 원한다면 자신의 아이디어를 반영하여 직접 플랫폼을 기획하고 설계해볼 수도 있습니다.

## 4. 핵심 강점과 방향성
본 강의의 중요한 강점은 `Modern Cloud 기반`으로 설계, 구축, 배포를 전개한다는 점입니다.  
매니지드 서비스를 적극 활용하여 짧은 시간 안에도 비교적 간결하면서 안정적이고 보안적으로 우수한 서비스를 빠르게 구현하고 배포하는 방식을 경험할 수 있습니다.

따라서 본 강의는 단편적인 기술 소개를 위한 과정이 아닙니다.  
`기획 → 요구사항 분석 → 설계 → 구축 → 배포`로 이어지는 전체 흐름을 실제로 경험하고, 하나의 MVP 프로젝트가 어떤 구조로 완성되며 이후 어떻게 고도화될 수 있는지까지 이해하도록 돕는 과정입니다.
