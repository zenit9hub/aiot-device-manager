## 1. 검토 범위
- 대상 폴더: `docs/강의 보조 자료/archived-reference-docs`
- 대상 파일 수: 23개
- 검토 기준:

## 2. 검토 결과 요약
- 다수 문서가 현행 루트 문서와 내용 중복 또는 구버전 확장본 성격.
- 구버전 경로(`aiot-device-manager-fe-working`, `aiot-dvc-mgr-be-2.0-refactoring`) 다수 포함.
- 아카이브 문서를 참조하지 않아도 현재 강의 운영에 필요한 핵심 정보 제공 가능.

## 4. 최종 처리
- 기본 정책(삭제 우선)에 따라 `archived-reference-docs` 전체 삭제 완료.
- 루트 문서의 `상세 버전 (아카이브 참고)` 문구를 `상세 버전 (현행화 통합본)`으로 교체 완료.

## 5. 복구 가능성
- 삭제된 파일은 Git 히스토리로 복구 가능.
- 필요 시 특정 파일만 선택 복구 후 `Superseded` 상태로 재보관 가능.
