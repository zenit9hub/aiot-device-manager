## 1. 적용 범위
- 적용 대상: `03. 기획 및 설계 산출물` 폴더 내 모든 문서
- 적용 시점: 신규 문서 작성 시점부터 즉시 적용

## 2. 버전 규칙
- 버전 형식: `vMajor.Minor.Patch`
- Major: 문서 구조 또는 범위의 큰 변경
- Minor: 섹션 추가/수정 등 의미 있는 내용 확장
- Patch: 오탈자/표현 개선/링크 수정

예시:
- `v1.0` 초기 승인본
- `v1.1` 내용 보강
- `v1.1.1` 경미한 수정

## 3. 문서 상태 규칙
| 상태 | 의미 | 전환 조건 |
|---|---|---|
| Draft | 작성 중 | 초안 작성 완료 전 |
| In Review | 검토 중 | 리뷰 요청 시 |
| Approved | 승인 완료 | 책임 승인자 승인 시 |
| Superseded | 대체됨 | 신규 문서로 대체 시 |

## 4. 문서 헤더 표준
각 문서는 제목/문서 목적 다음에 아래 형식을 유지한다.

```markdown
## 문서 정보
| 항목 | 값 |
|---|---|
| 문서 ID | PLAT-XXX-001 |
| 버전 | v1.0 |
| 작성일 | YYYY-MM-DD |
| 최종 수정일 | YYYY-MM-DD |
| 작성자 | 이름 |
| 승인자 | 이름 또는 TBD |
| 상태 | Draft/In Review/Approved/Superseded |
```

## 5. 변경 이력 표준
모든 문서 말미에 변경 이력 표를 유지한다.

```markdown
## 변경 이력
| 버전 | 일자 | 작성자 | 변경 내용 | 승인 |
|---|---|---|---|---|
| v1.0 | YYYY-MM-DD | 작성자 | 초기 작성 | - |
```
