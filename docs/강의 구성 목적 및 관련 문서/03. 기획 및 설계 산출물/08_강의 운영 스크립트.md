## 1. 운영 원칙
- 문서 설명은 “목적 → 핵심 포인트 → 코드 연결” 순으로 진행한다.
- 각 세션은 50분 진행 + 10분 휴식을 기본으로 한다.
- 질문은 세션 말미 5분에 집중 수집 후 정리한다.
