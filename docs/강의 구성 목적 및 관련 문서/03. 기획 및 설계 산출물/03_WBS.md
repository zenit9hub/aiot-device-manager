# WBS (Work Breakdown Structure) - AIoT 서비스 플랫폼 교육 프로젝트

## 문서 목적
이 문서는 “무엇을 언제 누가 어떤 산출물로 완료할지”를 작업 단위로 쪼개어, 일정/역할/완료기준을 명확히 하기 위한 문서입니다.  
기획 문서를 실제 실행 계획으로 변환하는 기준선으로 사용합니다.

## 1. WBS 운영 원칙
- 작업 단위는 산출물 중심으로 정의한다.
- 각 작업에는 책임 역할과 완료 기준(DoD)을 명시한다.
- 2일 교육 일정에 맞춰 필수/확장 작업을 구분한다.
